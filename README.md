## 📚 Learning Phases

### ✅ Phase 1 — Basics (requests + BeautifulSoup)
- HTTP GET requests
- HTML parsing fundamentals
- Extracting text, links, images
- Saving output to CSV and JSON

### 🔄 Phase 2 — Intermediate
- Handling pagination
- Custom headers and user-agents
- Error handling and retries
- Scrapy framework introduction

### ⏳ Phase 3 — Advanced
- Selenium for JavaScript sites
- Playwright for modern web apps
- Login and session handling
- Rate limiting and delays

### ⏳ Phase 4 — Production Ready
- Scheduling scrapers
- Storing data in databases
- Building scraping APIs with FastAPI
- Proxy rotation basics

## ⚖️ Legal & Ethics

All scraping in this portfolio follows ethical guidelines:

- Only public data is scraped
- `robots.txt` is always checked before scraping
- Delays are added between requests to avoid overloading servers
- No personal, private, or sensitive data is collected
- Projects are for learning and portfolio purposes only
